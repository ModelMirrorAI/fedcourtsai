We predict the Supreme Court will probably **not** take up this case (about a one-in-four chance that it does). Louisiana won in the lower court on its law requiring the Ten Commandments in classrooms. It filed this petition only as a backup, asking the Justices to hear its case if they agree to hear the similar Texas case, *Nathan v. Alamo Heights*. Even if the Court takes the Texas case, it can decide the main question without this one. So Louisiana's backup request is more likely to be turned down or set aside.
